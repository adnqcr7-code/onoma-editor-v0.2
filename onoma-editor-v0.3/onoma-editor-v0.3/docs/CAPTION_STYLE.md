# Caption Style

Captions use ASS subtitles so font, outline, alignment, timing, and inline word highlighting can be controlled precisely.

Current defaults:

- Font: Arial Black
- Size: 72
- Alignment: bottom center
- Maximum words per chunk: 4
- Karaoke highlight: `#3ecf8e`
- Pause-aware chunking: 0.6 seconds

Adjust these values in `src/config.py` or with the supported environment variables.
